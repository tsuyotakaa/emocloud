# emocloud

Десктопное приложение для Windows 10/11 x64: окно с настоящим soundcloud.com, сохранённый вход и трей, чтобы музыка не прерывалась.

Никаких надстроек над сайтом: интерфейс, плеер, лайки, плейлисты, волна — всё стандартное от SoundCloud.

## Что умеет

- Открывает `https://soundcloud.com/` в отдельном окне
- Запоминает вход (отдельный профиль WebView2, логин переживает перезапуск)
- Крестик прячет окно в трей, музыка продолжает играть
- Клик по иконке в трее — показать/скрыть окно
- Меню трея: «Открыть emocloud» / «Выход»
- Запоминает размер и позицию окна
- Внешние ссылки открывает в обычном браузере
- Второй запуск не создаёт второе окно, а показывает уже открытое
- Звук не засыпает при свёрнутом окне
- Показывает текущий трек в статусе Discord («Слушает emocloud»)

## Запуск

```
run.bat
```

`run.bat` ищет `emocloud.exe` рядом с собой, затем в `target\release` и в папке сборки. Можно запускать и напрямую:

```
emocloud.exe
```

Для запуска рядом с exe должен лежать `WebView2Loader.dll` — он уже лежит в папке проекта. Без него приложение молча не стартует.

Готовая сборка для друзей — в GitHub Releases: скачать `emocloud-portable.zip`, распаковать в любую папку и запустить `emocloud.exe`.

## Вход

1. В окне приложения нажми **Sign in**.
2. Войди по **email и паролю** — этот способ работает всегда.
3. Логин сохранится в профиле приложения и больше спрашиваться не будет.

> Вход через Google в WebView2 может быть заблокирован самим Google. Если он не работает — используй email.

## Трей

- Закрытие окна (крестик) **не выключает** приложение.
- Полный выход: правый клик по иконке в трее → **«Выход»**.
- Если иконки не видно — она может быть в скрытых значках рядом с часами.

## Discord

Если Discord запущен, в статусе показывается текущий трек:

- название трека и исполнитель;
- обложка;
- время прослушивания;
- кнопка «Слушать в SoundCloud»;
- в заголовке активности — название приложения **emocloud**.

Ничего настраивать не нужно. Если статус не появляется:

1. Проверь, что запущено десктопное приложение Discord (не браузер).
2. Загляни в `%LOCALAPPDATA%\com.artur.soundcloudrust\presence.log` — там видно, подключилось ли приложение и какой трек отправляло.

Application ID: `1570051660976365588`. Подпись «emocloud» берётся из имени приложения в Discord Developer Portal.

## Где хранятся данные

- Профиль (куки, вход): `%LOCALAPPDATA%\com.artur.soundcloudrust\profile`
- Состояние окна: `%APPDATA%\com.artur.soundcloudrust`
- Лог Discord-статуса: `%LOCALAPPDATA%\com.artur.soundcloudrust\presence.log`

Удаление папки профиля сбрасывает вход.

> Идентификатор приложения намеренно оставлен прежним (`com.artur.soundcloudrust`), чтобы сохранённый вход не слетел после переименования в emocloud.

## Иконки

Все иконки делаются из одной картинки:

- `icons\source.png` — исходник для иконки приложения (exe, окно, панель задач)
- `assets\tray-source.png` — исходник для иконки в трее

Пересобрать набор:

```powershell
powershell -ExecutionPolicy Bypass -File tools\make-icons.ps1
```

Скрипт создаёт `icons\icon.ico` (16, 24, 32, 48, 64, 128, 256), `icons\32x32.png`, `icons\128x128.png`, `icons\128x128@2x.png`, `icons\icon.png` и `assets\tray.png` (32×32) с `assets\tray@2x.png` (64×64).

`build.rs` помечает иконки как зависимости сборки, поэтому после замены картинки обычный `cargo build --release` пересоберёт exe с новой иконкой.

## Сборка из исходников

Нужен Rust. WebView2 Runtime в Windows 10/11 обычно уже установлен.

Обычная сборка (MSVC-тулчейн, по умолчанию у rustup):

```bat
winget install Rustlang.Rustup
cargo build --release
```

Готовый exe: `target\release\emocloud.exe`. Рядом с ним нужен `WebView2Loader.dll` — он лежит в папке проекта.

Если собираешь GNU-тулчейном с MinGW (так собрана версия в Releases):

```bat
rustup default stable-x86_64-pc-windows-gnu
winget install BrechtSanders.WinLibs.POSIX.MSVCRT
cargo build --release
```

### Если путь к проекту содержит кириллицу

GNU `ld` и `windres` не понимают не-ASCII символы в путях. В этом случае скопируй `.cargo\config.toml.example` в `.cargo\config.toml` и раскомментируй нужные строки:

- `target-dir` — вынести папку сборки в ASCII-путь;
- `linker` — указать `x86_64-w64-mingw32-gcc.exe`, если MinGW не в `PATH`;
- `rustflags = ["-C", "link-self-contained=no"]` — для GNU-сборки.

`.cargo\config.toml` — личный файл, в git он не попадает.

## Ограничения

- Это не официальный клиент SoundCloud.
- Внутри — системный WebView2 (Edge), поэтому сайт ведёт себя как в браузере на Chromium.
- Если SoundCloud сильно поменяет разметку — приложение это никак не затронет, потому что мы не вмешиваемся в интерфейс сайта.
- Скачивание треков доступно только там, где его разрешает сам SoundCloud (кнопка Download на странице трека).
- Поддерживается Windows 10/11 x64; 32-битная Windows не поддерживается.
